Cybersecurity 101: Get Off that Vibe Coded Website

Valentina Falanga & Malayka Mudassar

about skills projects

If you feel like everything online has gotten worse recently, you aren’t imagining things. With the rise of AI, no corner of the internet was left untouched. Of course, this includes app and website development. You may have heard the phrase “vibe coding” being thrown around. Unfortunately, this is an extremely misleading name to anyone unfamiliar with it. Vibe coding describes the use of almost entirely (or entirely) generative AI to build a website or app. In other words, coding based on “vibe.” Oftentimes, this is someone with very little to no coding experience building an entire app using AI prompts. Without proper oversight, these vibe coded programs are about as well put together as a bridge made of toothpicks and scotch tape. That is to say, they are not exactly stable, or safe. Apiiro, an application security platform, analyzed code from thousands of code repositories, coding assistants and developers across Fortune 50 enterprises. Their findings showed that AI dropped trivial errors in syntax (spelling errors in the code) by 76%. In turn, they found that architectural design flaws increased by 153%. This includes errors such as broken authorization flows and insecure designs. In simpler terms, it lacks the security measures needed to ward off potential attacks. Quite the tradeoff.
